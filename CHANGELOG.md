## [0.1.0] - 2026-10-13

### Added

- The Sepp’s Workshop theme for the Starship prompt, generated from the prompt roles of `@sepps-workshop/design-system`. It ships as two files with the same colours: `themes/sepps-workshop.toml` repaints Starship's default prompt, `themes/sepps-workshop-custom.toml` adds a two-line layout with the time at the right edge.
- Tests that derive every expected value from the design system and draw a prompt with the real Starship.
